# Presentation

`nachalniki_logistics.pptx` is the Ukrainian draft deck: 10 main slides (about 6 minutes, demo included) and 2 appendix slides. The Stage 1 slides are filled from the 2026-10-07 runs. The Silver, Gold, demo and results slides hold placeholders marked «ЗАПОВНИТИ · <name>», and the speaker notes say what to insert and who owns it.

The deck is generated by `build_deck.js` (pptxgenjs). You can edit the PPTX directly, or change the script and rebuild it:

```bash
cd presentation
npm install --no-save pptxgenjs@4.0.1
node build_deck.js
```

**Rebuilding overwrites `nachalniki_logistics.pptx`, so any manual edits made in PowerPoint are lost.** Pick one way of editing and stick to it. The appendix images are read from `docs/slides/img/`.
